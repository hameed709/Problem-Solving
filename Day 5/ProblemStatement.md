Day 5 — Problem: Valid Anagram

Problem Statement

Given two strings s and t, determine whether t is an anagram of s.

An anagram is formed by rearranging the letters of another word, using all the original letters exactly once.

Return true if t is an anagram of s, otherwise return false.

Example 1

Input:
s = "listen"
t = "silent"

Output:
true

Example 2

Input:
s = "hello"
t = "world"

Output:
false

Example 3

Input:
s = "triangle"
t = "integral"

Output:
true

Constraints:
- 1 <= s.length, t.length <= 100
- s and t contain only lowercase English letters.

Challenge:
Solve the problem without using any built-in sorting functions.
