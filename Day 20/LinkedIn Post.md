Today’s problem: Contains Duplicate 🔍
The goal was simple: determine whether an array contains any duplicate value.
💡 Approach:
I used a hash-based data structure to keep track of the elements I had already seen.
As soon as an element appeared again, I returned True instead of continuing through the array.
⚡ Complexity:
• Time: O(n)
• Space: O(n)
• No nested loops
• Early return when a duplicate is found
One small improvement I made was switching from a dictionary to a Set, since I only needed to track whether a value had appeared—not store a frequency.
