Day 4 — Problem: Longest Common Prefix

Problem Statement

Given an array of strings, find the longest common prefix shared by all the strings.

If there is no common prefix, return an empty string ("").

Example 1

Input:
["flower", "flow", "flight"]

Output:
"fl"

Example 2

Input:
["dog", "racecar", "car"]

Output:
""

Example 3

Input:
["interview", "internet", "internal"]

Output:
"inter"

Constraints:
- 1 <= strings.length <= 100
- 0 <= strings[i].length <= 100
- All strings contain only lowercase English letters.

Challenge:
Solve the problem without using any built-in prefix functions.
