Day 3 — Problem: Remove Duplicate Characters

Given a string, remove all duplicate characters while keeping only the first occurrence of each character.

The order of characters should remain the same as in the original string.

Example 1

Input:

"programming"

Output:

"progamin"

Example 2

Input:

"banana"

Output:

"ban"

Example 3

Input:

"mississippi"

Output:

"misp"

Challenge: Solve the problem without using set().
