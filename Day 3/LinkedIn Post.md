🚀 Day 3 of My Daily Problem Solving Challenge
Today's challenge was to remove duplicate characters from a string while preserving the order of their first occurrence.
🧩 Problem Statement
Given a string, remove all duplicate characters while keeping only the first occurrence of each character. The order of characters should remain unchanged.
Examples:
"programming" → "progamin"
"banana" → "ban"
"mississippi" → "misp"
💡 Challenge: Solve the problem without using set().
💻 My Approach
I solved this by using a dictionary to keep track of characters as I traversed the string. Since dictionaries preserve insertion order in modern Python, joining the dictionary keys produces the required output while avoiding the use of set().
