🧩 Problem: Longest Word in a Sentence
Problem Statement:
Given a sentence containing multiple words, find the longest word.
📌 If two or more words have the same maximum length, return the first one.
Example:
Input:
"Python programming is interesting"
Output:
"programming"
💡 Challenge
Solve the problem without using max().
Today, I solved this problem by focusing on string manipulation, iteration, conditional logic, and edge cases such as words with the same length.
