Day 2 — Problem: Longest Word in a Sentence

Given a string containing multiple words, find the longest word in the sentence.

If two or more words have the same maximum length, return the first word among them.

Example 1

Input:

"Python programming is interesting"

Output:

"programming"

Example 2

Input:

"I love coding daily"

Output:

"coding"

Challenge: Solve the problem without using max().
