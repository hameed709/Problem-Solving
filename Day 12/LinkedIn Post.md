Today’s problem: Two Sum 🧠
Given an array and a target, the goal was to find the indices of two numbers that add up to the target.
My first approach was checking adjacent elements, but I realized that Two Sum doesn’t require the numbers to be next to each other.
The key idea was using a HashMap (Dictionary) to store previously seen numbers and their indices.
For each number:
Required number = Target − Current number
Then I check whether that required number has already been seen.
⏱️ Time Complexity: O(n)
💾 Space Complexity: O(n)
This was a good reminder that sometimes the biggest improvement isn't writing more code — it's changing the way you think about the problem.
