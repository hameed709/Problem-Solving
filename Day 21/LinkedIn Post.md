Day 21 — Intersection of Two Arrays 🔥
Wrapped up Day 21 of my Problem-Solving Challenge! 💻
Today’s problem was about finding the unique elements common to two arrays.
At first, I solved it using lists, but there was a problem: checking whether an element exists in a list can take O(n) time.
So I switched to HashSet 🚀
🔹 Convert the second array into a set for fast lookups
🔹 Use another set to automatically handle duplicates
🔹 Traverse the first array once
🔹 No sorting. No nested loops.
⏱️ Time Complexity: O(n + m)
💾 Space Complexity: O(m + k)
The biggest takeaway from today:
Choosing the right data structure can completely change the efficiency of your solution.
